Daily Wins v7

Automatic day rollover:
- Removed Finish Day & Archive.
- Removed Move unfinished tasks to next day.
- The current day ends automatically at midnight local time.
- When a new day begins:
  • The previous day is automatically archived.
  • Completed tasks remain recorded in that archived day.
  • Unfinished normal tasks carry forward unchecked.
  • Recurring tasks do not carry forward.
  • Each recurring template creates one fresh unchecked task for the new day.
- If the app is closed or asleep at midnight, rollover happens automatically when it is next opened/resumed.
- If the app stays open, a timer triggers just after midnight.
- Streaks still count only from Today's To-Do completions.
- Existing user data remains compatible through the same dailyWins.v2 localStorage key.
